On-Device Visual Perception for Light-weight Browser Agents

Browser agents must execute web navigation tasks autonomously while preserving end-user privacy. By deploying local lightweight visual perception and DOM parsing directly inside the browser extension, raw sensitive information is scrubbed before any data reaches external VLM or LLM endpoints.

Architecture Overview

The system utilizes multi-modal sensor fusion across structured DOM trees, on-device OCR providers, and visual spatial detectors to guarantee zero-leakage execution.
